IntelliStock - exploratory data analysis and column decisions
======================================================================
Source file : sales_data.csv
Raw rows    : 76,000
Raw columns : 16

The raw file is used exactly as downloaded. Columns are selected and
excluded in code (features.py), never by editing the CSV, so the
pipeline reproduces the same result from the original download.

COLUMNS USED
----------------------------------------------------------------------
  Date                     -> date
  Product ID               -> product
  Units Sold               -> units_sold
  Category                 -> category
  Store ID                 -> store
  Units Ordered            -> units_ordered

COLUMNS EXCLUDED, WITH REASONS
----------------------------------------------------------------------
  Region
      Constant within a store, so it adds no signal beyond the store identifier.
  Inventory Level
      Supplied live from the StockItem table at inference, not learned from.
  Price
      Excluded from v1.0 - price effects need a dynamic-pricing model (out of scope).
  Discount
      Excluded from v1.0 - promotions are not modelled in the current scope.
  Weather Condition
      Not available at inference time without a weather feed (out of scope).
  Promotion
      Excluded from v1.0 - promotions are not modelled in the current scope.
  Competitor Pricing
      Not collected by IntelliStock; suppliers self-report their own prices.
  Seasonality
      Redundant - month and day-of-week features already capture this.
  Epidemic
      Not available at inference time; the live system has no such flag.
  Demand
      Target leakage - a pre-computed estimate of the value being predicted.
